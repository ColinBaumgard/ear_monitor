# Ear Monitor

A simple hearing monitor script that plays tones at different frequencies and asks the user to rate how well they hear each one.

## Setup

1. Create a Python virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

```bash
python tone_slider.py
```
